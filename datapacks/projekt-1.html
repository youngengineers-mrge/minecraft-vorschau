Projekt 1 – Mein erstes Datapack

Young Engineers · Minecraft Java 26.2 · Lernweg Datapacks

← Alle ProjekteMinecraft-Übersicht

Bevor du beginnst

  1. Starte Minecraft Java 26.2 und öffne eine eigene Testwelt im Kreativmodus mit erlaubten Befehlen.
  2. Öffne den Weltordner: Welt auswählen → Bearbeiten → Weltordner öffnen (falls diese Schaltfläche in deinem Launcher fehlt: .minecraft/saves/WELTNAME).
  3. Öffne darin den Ordner datapacks. Erstelle dort den jeweils genannten Projektordner.
  4. Erstelle Dateien mit VS Code oder einem Texteditor. Dateiendungen sichtbar machen; es darf nicht versehentlich .txt angehängt werden.
  5. Nach Änderungen im Spiel /reload eingeben. Im Chat zeigt /datapack list die geladenen Pakete.

Nur in einer Testwelt arbeiten. Befehle, die Blöcke setzen oder entfernen, können Bauwerke verändern. Vor größeren Versuchen die Welt sichern.

Ordner anlegen

Erstelle im Weltordner unter datapacks einen Ordner namens young_01_start. Darin liegt direkt die Datei pack.mcmeta (nicht in einem weiteren Unterordner). Erstelle sie mit diesem Inhalt:

{
  "pack": {
    "description": "Young Engineers – Lernprojekt",
    "min_format": [107, 1],
    "max_format": 107
  }
}

Die Datapack-Version 107.1 gilt für Minecraft Java 26.2. Das unterscheidet sich von der Resourcepack-Version.

1. Die erste Funktion

Erstelle nacheinander die Ordner data, young und function. Lege dort willkommen.mcfunction ab. Dein Ergebnis muss so aussehen:

datapacks/
└── young_01_start/
    ├── pack.mcmeta
    └── data/
        └── young/
            └── function/
                └── willkommen.mcfunction

Schreibe in die Datei willkommen.mcfunction genau diese zwei Zeilen:

say Willkommen bei Young Engineers!
experience add @s 5 points

Speichere die Datei mit Strg+S. In Minecraft: /reload, dann /function young:willkommen.

Was soll passieren? Im Chat erscheint die Nachricht. Du erhältst fünf Erfahrungspunkte. Der Name links vom Doppelpunkt (young) entspricht dem Namespace-Ordner. Der Name rechts (willkommen) entspricht dem Dateinamen ohne Endung.

2. Selbst verändern

  1. Ersetze die Nachricht durch deinen eigenen Text.
  2. Ändere 5 in 10.
  3. Speichere, führe /reload aus und rufe die Funktion erneut auf.

3. Verständnisfrage

Warum funktioniert die Eingabe /function young:willkommen.mcfunction nicht? Was passiert, wenn function versehentlich functions heißt?

Prüfung – erst abhaken, dann weitergehen

  • /reload meldet keinen Fehler.
  • Das Paket wird mit /datapack list angezeigt.
  • Die Funktion /function young:willkommen funktioniert.
  • Die selbst geänderte Nachricht und Punktzahl erscheinen.

Falls etwas nicht funktioniert: zuerst Dateinamen, Endungen, Ordnerstruktur und die Schreibweise des Befehls prüfen. Der Inhalt einer .mcfunction-Datei steht ohne führenden Schrägstrich; im Minecraft-Chat steht der Schrägstrich davor.
