Projekt 6 – Die Schatzsuche

Young Engineers · Minecraft Java 26.2 · Lernweg Datapacks

← Alle ProjekteMinecraft-Übersicht

Bevor du beginnst

  1. Starte Minecraft Java 26.2 und öffne eine eigene Testwelt im Kreativmodus mit erlaubten Befehlen.
  2. Öffne den Weltordner: Welt auswählen → Bearbeiten → Weltordner öffnen (falls diese Schaltfläche in deinem Launcher fehlt: .minecraft/saves/WELTNAME).
  3. Öffne darin den Ordner datapacks. Erstelle dort den jeweils genannten Projektordner.
  4. Erstelle Dateien mit VS Code oder einem Texteditor. Dateiendungen sichtbar machen; es darf nicht versehentlich .txt angehängt werden.
  5. Nach Änderungen im Spiel /reload eingeben. Im Chat zeigt /datapack list die geladenen Pakete.

Nur in einer Testwelt arbeiten. Befehle, die Blöcke setzen oder entfernen, können Bauwerke verändern. Vor größeren Versuchen die Welt sichern.

Ordner anlegen

Erstelle im Weltordner unter datapacks einen Ordner namens young_06_schatzsuche. Darin liegt direkt die Datei pack.mcmeta (nicht in einem weiteren Unterordner). Erstelle sie mit diesem Inhalt:

{
  "pack": {
    "description": "Young Engineers – Lernprojekt",
    "min_format": [107, 1],
    "max_format": 107
  }
}

Die Datapack-Version 107.1 gilt für Minecraft Java 26.2. Das unterscheidet sich von der Resourcepack-Version.

Ziel

Ein Abenteuer führt über drei Stationen zu einer verschlossenen Schatzkammer. Erst wer die Aufgaben in der richtigen Reihenfolge löst, erhält den Schatz.

  1. Baue drei Stationen: Eingang, Rätselraum und Schatzkammer.
  2. Überlege, welche Gegenstände an jeder Station zu finden sind.
  3. Erstelle data/young/function/start.mcfunction:
scoreboard objectives add young_stufe dummy
scoreboard players set @s young_stufe 0
tellraw @s {"text":"Die Schatzsuche beginnt! Suche Station 1.","color":"gold"}

Teste mit /reload und /function young:start. Die Variable young_stufe hält den aktuellen Fortschritt des Spielers fest.

Ausbau: Jede Station kontrolliert die vorherige Stufe und erhöht sie um eins. Für das finale Spiel folgen automatische Auslöser und die Prüfung der Schatzkammer.

Prüfung – erst abhaken, dann weitergehen

  • /reload meldet keinen Fehler.
  • Das Paket wird mit /datapack list angezeigt.
  • Die Startnachricht erscheint.
  • Die Fortschrittsvariable wird eingerichtet.

Falls etwas nicht funktioniert: zuerst Dateinamen, Endungen, Ordnerstruktur und die Schreibweise des Befehls prüfen. Der Inhalt einer .mcfunction-Datei steht ohne führenden Schrägstrich; im Minecraft-Chat steht der Schrägstrich davor.
