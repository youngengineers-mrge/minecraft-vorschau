Projekt 2 – Der magische Schalter

Young Engineers · Minecraft Java 26.2 · Lernweg Datapacks

← Alle ProjekteMinecraft-Übersicht

Bevor du beginnst

  1. Starte Minecraft Java 26.2 und öffne eine eigene Testwelt im Kreativmodus mit erlaubten Befehlen.
  2. Öffne den Weltordner: Welt auswählen → Bearbeiten → Weltordner öffnen (falls diese Schaltfläche in deinem Launcher fehlt: .minecraft/saves/WELTNAME).
  3. Öffne darin den Ordner datapacks. Erstelle dort den jeweils genannten Projektordner.
  4. Erstelle Dateien mit VS Code oder einem Texteditor. Dateiendungen sichtbar machen; es darf nicht versehentlich .txt angehängt werden.
  5. Nach Änderungen im Spiel /reload eingeben. Im Chat zeigt /datapack list die geladenen Pakete.

Nur in einer Testwelt arbeiten. Befehle, die Blöcke setzen oder entfernen, können Bauwerke verändern. Vor größeren Versuchen die Welt sichern.

Ordner anlegen

Erstelle im Weltordner unter datapacks einen Ordner namens young_02_schalter. Darin liegt direkt die Datei pack.mcmeta (nicht in einem weiteren Unterordner). Erstelle sie mit diesem Inhalt:

{
  "pack": {
    "description": "Young Engineers – Lernprojekt",
    "min_format": [107, 1],
    "max_format": 107
  }
}

Die Datapack-Version 107.1 gilt für Minecraft Java 26.2. Das unterscheidet sich von der Resourcepack-Version.

Ziel und Aufbau

Mit zwei Datapack-Befehlen schaltest du eine entfernte Redstone-Lampe ein und aus – ohne verlegte Redstone-Leitung. Zunächst übernehmen zwei Befehle im Chat den Schalter; später kommen echte Auslöser hinzu.

  1. Gehe in einen freien Bereich der Testwelt.
  2. Gib im Chat /setblock 0 65 0 minecraft:redstone_lamp ein. Falls dort etwas Wichtiges steht, verwende stattdessen eine freie Position und passe alle Koordinaten unten an.
  3. Die Lampe befindet sich jetzt bei X=0, Y=65, Z=0. Der Block direkt darunter liegt bei 0 64 0.

Die angegebenen Koordinaten sind Beispielwerte, keine automatische Standortbestimmung. Wähle bei Bedarf einen anderen freien Standort, bevor du Befehle ausführst.

Die beiden Funktionen

Erstelle die Ordner data/young/function. Lege darin die Dateien lampe_an.mcfunction und lampe_aus.mcfunction an.

young_02_schalter/
├── pack.mcmeta
└── data/
    └── young/
        └── function/
            ├── lampe_an.mcfunction
            └── lampe_aus.mcfunction

lampe_an.mcfunction:

setblock 0 64 0 minecraft:redstone_block
say Die Lampe ist eingeschaltet.

lampe_aus.mcfunction:

setblock 0 64 0 minecraft:stone
say Die Lampe ist ausgeschaltet.

Speichere beide Dateien. Gib im Spiel der Reihe nach ein:

/reload
/function young:lampe_an
/function young:lampe_aus

Beobachte: Das Datapack setzt unter der Lampe einen Redstone-Block (Strom an) oder einen normalen Steinblock (Strom aus). Die Lampe reagiert darauf.

Selbst ausprobieren

  1. Ersetze im Ausschalt-Befehl minecraft:stone durch minecraft:air. Was verändert sich sichtbar?
  2. Verschiebe die Lampe an einen anderen Ort. Passe beide Koordinaten an.
  3. Erkläre den Unterschied zwischen lampe_an und lampe_aus.

Ausblick: Ein echter Hebel kann in einer späteren Ausbaustufe durch regelmäßige Zustandsprüfung eingebunden werden. Dieses erste Projekt trennt bewusst die einfache Lampensteuerung von der schwierigeren Ereigniserkennung.

Prüfung – erst abhaken, dann weitergehen

  • /reload meldet keinen Fehler.
  • Das Paket wird mit /datapack list angezeigt.
  • Die Lampe geht nach /function young:lampe_an an.
  • Die Lampe geht nach /function young:lampe_aus aus.

Falls etwas nicht funktioniert: zuerst Dateinamen, Endungen, Ordnerstruktur und die Schreibweise des Befehls prüfen. Der Inhalt einer .mcfunction-Datei steht ohne führenden Schrägstrich; im Minecraft-Chat steht der Schrägstrich davor.
