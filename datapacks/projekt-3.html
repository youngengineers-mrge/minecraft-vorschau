Projekt 3 – Das Zahlenschloss

Young Engineers · Minecraft Java 26.2 · Lernweg Datapacks

← Alle ProjekteMinecraft-Übersicht

Bevor du beginnst

  1. Starte Minecraft Java 26.2 und öffne eine eigene Testwelt im Kreativmodus mit erlaubten Befehlen.
  2. Öffne den Weltordner: Welt auswählen → Bearbeiten → Weltordner öffnen (falls diese Schaltfläche in deinem Launcher fehlt: .minecraft/saves/WELTNAME).
  3. Öffne darin den Ordner datapacks. Erstelle dort den jeweils genannten Projektordner.
  4. Erstelle Dateien mit VS Code oder einem Texteditor. Dateiendungen sichtbar machen; es darf nicht versehentlich .txt angehängt werden.
  5. Nach Änderungen im Spiel /reload eingeben. Im Chat zeigt /datapack list die geladenen Pakete.

Nur in einer Testwelt arbeiten. Befehle, die Blöcke setzen oder entfernen, können Bauwerke verändern. Vor größeren Versuchen die Welt sichern.

Ordner anlegen

Erstelle im Weltordner unter datapacks einen Ordner namens young_03_zahlenschloss. Darin liegt direkt die Datei pack.mcmeta (nicht in einem weiteren Unterordner). Erstelle sie mit diesem Inhalt:

{
  "pack": {
    "description": "Young Engineers – Lernprojekt",
    "min_format": [107, 1],
    "max_format": 107
  }
}

Die Datapack-Version 107.1 gilt für Minecraft Java 26.2. Das unterscheidet sich von der Resourcepack-Version.

Ein Vier-Bit-Code

Vier Schalter werden zuerst als vier gespeicherte Zahlen dargestellt. Der richtige Code lautet 1010. So kannst du die Prüflogik verstehen, bevor die Schalter tatsächlich aus der Welt ausgelesen werden.

Erstelle data/young/function und die drei Dateien start.mcfunction, code_richtig.mcfunction, pruefen.mcfunction.

start.mcfunction:

scoreboard objectives add young_code dummy
scoreboard players set #s1 young_code 1
scoreboard players set #s2 young_code 0
scoreboard players set #s3 young_code 1
scoreboard players set #s4 young_code 0
say Zahlenschloss vorbereitet.

Der Befehl scoreboard objectives add muss nur einmal ausgeführt werden. Bei einem zweiten Start kann die Meldung „existiert bereits“ erscheinen. Das ist in dieser Übung kein Problem.

code_richtig.mcfunction:

say Code erkannt! Die Tür darf geöffnet werden.

pruefen.mcfunction (alles eine einzige Befehlszeile):

execute if score #s1 young_code matches 1 if score #s2 young_code matches 0 if score #s3 young_code matches 1 if score #s4 young_code matches 0 run function young:code_richtig

Speichere alle Dateien. Führe anschließend aus:

/reload
/function young:start
/function young:pruefen

Erwartung: Code erkannt!

Fehler provozieren

  1. Gib /scoreboard players set #s2 young_code 1 ein.
  2. Rufe /function young:pruefen erneut auf. Jetzt darf keine Erfolgsmeldung erscheinen.
  3. Setze #s2 wieder auf 0; prüfe erneut.

Die Namen #s1 bis #s4 sind interne Speicherplätze, keine Spielernamen. if score verhält sich wie eine Bedingung in Python.

Nächste Erweiterung: Eine Funktion für den falschen Code und danach vier echte Hebel über execute if block auswerten. Wir führen diese Erweiterungen erst nach deinem Grundtest aus.

Vertiefung: Scoreboard-Variablen und Treffer zählen

objectives legt einen Speicherbereich an; players setzt, verändert oder liest die gespeicherten Werte. Ein Wert gehört immer zu einem Namen und einem Scoreboard.

/scoreboard objectives add richtige dummy
/scoreboard players set @s richtige 0
/scoreboard players add @s richtige 1
/scoreboard players get @s richtige

#s1 young_code ist unser gemeinsamer Schalterwert. @s richtige ist der Zähler des Spielers, der den Befehl im Chat aufruft. Der Befehl zum Anlegen mit objectives add ist nur einmal nötig.

Neue Funktion: pruefen_zaehler.mcfunction

Lege diese Datei zusätzlich im vorhandenen Ordner data/young/function an. Sie enthält die folgenden Befehle ohne / am Zeilenanfang:

scoreboard players set @s richtige 0
execute if score #s1 young_code matches 1 run scoreboard players add @s richtige 1
execute if score #s2 young_code matches 0 run scoreboard players add @s richtige 1
execute if score #s3 young_code matches 1 run scoreboard players add @s richtige 1
execute if score #s4 young_code matches 0 run scoreboard players add @s richtige 1
execute if score @s richtige matches 4 run function young:code_richtig

Das erste Zurücksetzen verhindert, dass bei wiederholter Prüfung immer weitergezählt wird. Die Zahl 4 bedeutet: Alle vier Schalterstellungen sind richtig.

Test im Minecraft-Chat

/scoreboard objectives add richtige dummy
/reload
/function young:start
/function young:pruefen_zaehler
/scoreboard players get @s richtige

Erwartet wird 4 und die Erfolgsmeldung. Teste danach:

/scoreboard players set #s3 young_code 0
/function young:pruefen_zaehler
/scoreboard players get @s richtige

Jetzt werden 3 richtige Schalter angezeigt, ohne Erfolgsmeldung. Die Funktion ist für den Aufruf durch einen Spieler gedacht: @s muss auf einen Spieler zeigen.

Zusatzaufgabe: Dein Code 1001

Für den Code 1001 stellst du in start.mcfunction S3 auf 0 und S4 auf 1. Ändere im Zähler die erwarteten Werte für S3 und S4 ebenfalls auf 0 und 1. Damit sollte der Zähler wieder 4 liefern. Die ursprüngliche Funktion pruefen.mcfunction prüft solange weiterhin 1010, bis du auch sie anpasst.

Merksatz: objectives bestimmt, welche Werte gespeichert werden. players bestimmt, für wen diese Werte gesetzt oder verändert werden.

Prüfung – erst abhaken, dann weitergehen

  • /reload meldet keinen Fehler.
  • Das Paket wird mit /datapack list angezeigt.
  • Der richtige Code 1010 löst die Erfolgsmeldung aus.
  • Der absichtlich falsche Code löst keine Erfolgsmeldung aus.

Falls etwas nicht funktioniert: zuerst Dateinamen, Endungen, Ordnerstruktur und die Schreibweise des Befehls prüfen. Der Inhalt einer .mcfunction-Datei steht ohne führenden Schrägstrich; im Minecraft-Chat steht der Schrägstrich davor.
