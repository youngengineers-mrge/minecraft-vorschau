Projekt: Zahlenschloss-Profi

Vier Hebel, ein veränderbarer Geheimcode und eine Prüfung auf Tastendruck

← Zur Datapack-Übersicht

Das lernst du

Du liest Schalter mit execute if block, speicherst Ist- und Sollwerte in Scoreboards und vergleichst beide mit execute if score … = … run. Die Prüfung startet nur beim Drücken des Tasters – keine dauerhafte Tick-Funktion erforderlich.

Version 0.1, Minecraft Java 26.2. Die Logik ist vorbereitet, aber noch nicht direkt in Minecraft getestet. Die Hebelkoordinaten müssen angepasst werden. Die Türöffnung wird zunächst nur durch eine Nachricht dargestellt.

1 · Vorbereitung

  1. Lege vier Hebel S1–S4 an. Notiere die Blockkoordinaten jedes Hebels.
  2. Öffne unten die Datei schalter_lesen.mcfunction und ändere die vier Beispielpositionen (100 65 200 usw.) auf deine Werte.
  3. Erstelle aus den Quelldateien einen Datapack-Ordner oder lade das komplette ZIP aus dem Projektarchiv deiner ChatGPT-Dateien. In der Welt muss pack.mcmeta direkt im Datapack-Ordner liegen.
  4. Starte Minecraft mit aktivierten Befehlen und gib /reload ein.
  5. Mit /function zahlenschloss_profi:code_1001 setzt du den Geheimcode 1001.

2 · Taster anschließen

Setze einen Impuls-Befehlsblock auf Benötigt Redstone und verbinde ihn mit dem Prüftaster. In den Befehlsblock kommt (ohne Slash):

execute as @p[distance=..5] run function zahlenschloss_profi:pruefen

Für einen ersten Test kannst du als Spieler auch /function zahlenschloss_profi:pruefen eingeben. Achtung: Der Befehlsblock erfasst den nächstgelegenen Spieler innerhalb von fünf Blöcken.

3 · So funktioniert die Prüfung

function zahlenschloss_profi:schalter_lesen
scoreboard players set @s zsp_richtig 0
execute if score #s1 zsp_code = #x1 zsp_code run scoreboard players add @s zsp_richtig 1
execute if score #s2 zsp_code = #x2 zsp_code run scoreboard players add @s zsp_richtig 1
execute if score #s3 zsp_code = #x3 zsp_code run scoreboard players add @s zsp_richtig 1
execute if score #s4 zsp_code = #x4 zsp_code run scoreboard players add @s zsp_richtig 1
execute if score @s zsp_richtig matches 4 run function zahlenschloss_profi:richtig
execute unless score @s zsp_richtig matches 4 run function zahlenschloss_profi:falsch

Die vier Schalterwerte heißen #s1 bis #s4; der geheime Sollcode liegt in #x1 bis #x4. Bei vier Treffern erscheint die Erfolgsmeldung.

4 · Code ändern, ohne die Prüfung umzuschreiben

/scoreboard players set #x1 zsp_code 0
/scoreboard players set #x2 zsp_code 1
/scoreboard players set #x3 zsp_code 1
/scoreboard players set #x4 zsp_code 0

Damit gilt der neue Geheimcode 0110.

Quelldateien und Arbeitsaufträge

Die einzelnen Dateien stehen im Projektordner auf GitHub bereit:

  • schalter_lesen.mcfunction – Hebelpositionen ändern
  • pruefen.mcfunction – Logik untersuchen
  • code_1001.mcfunction – Sollwerte
  • pack.mcmeta – Datapack-Metadaten

Deine Aufgaben

  1. Baue und beschrifte vier Hebel.
  2. Teste den Code 1001 und danach eine falsche Kombination.
  3. Erkläre die Wörter execute, if score, = und run.
  4. Ändere den Geheimcode auf 0110, ohne pruefen.mcfunction zu ändern.
  5. Profi-Aufgabe: Ergänze eine zeitgesteuerte Türöffnung.
